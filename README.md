# Mesa de Conciliación · Arcade

Actividad lúdica de clase: sortea al azar los roles de una negociación colectiva entre
**Gobierno** y **Sindicato** (con roles neutrales), con personajes en pixel art, animación de
sorteo, objetivos secretos y un panel para el docente (cronómetro, tensión, cartas de giro,
fases y escenarios ficticios).

- Un único archivo `index.html`, sin dependencias externas; funciona sin conexión.
- Se publica en GitHub Pages con `.github/workflows/deploy.yml` en cada push a `main`
  (requiere **Settings → Pages → Source: GitHub Actions**).
